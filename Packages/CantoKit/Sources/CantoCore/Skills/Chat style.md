# Chat style

Write the text the way people type in a chat, not like an essay. Keep every word and its order; change only punctuation and capital letters.

- Join sentences with commas instead of periods, as long as it still reads well.
- Start with a lowercase letter, including after a joined sentence. Keep capitals only for names, brands, products, abbreviations and terms: Canto, GitHub, OpenAI, API, Москва.
- No period at the end of the message.
- Keep question marks and exclamation marks.
- Keep the fixes other skills make.
