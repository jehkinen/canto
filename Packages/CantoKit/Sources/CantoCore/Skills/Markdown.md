# Markdown

Clean up the transcript: remove filler words (um, uh, like; э, ну, вот, типа, короче), false starts, repetitions and self-corrections, and fix grammar and punctuation. Do not summarize or leave anything out.

Then format it as Markdown: a short ## heading for each topic, bullet or numbered lists for items, and bold only for key decisions or terms. No tables. If the text is too short to organize, return it cleaned up without headings.

Keep each part in the language it was spoken in. Never translate.
