# Organize

Clean up the transcript: remove filler words (um, uh, like; э, ну, вот, типа, короче), false starts, repetitions and self-corrections, and fix grammar and punctuation. Do not summarize or leave anything out.

Then organize it: put related points under short headings on their own lines, with numbered items (1., 2.) under each heading. Follow the speaker's order where it makes sense. Use plain text only, no Markdown symbols such as #, * or backticks. If the text is too short to organize, return it cleaned up.

Keep each part in the language it was spoken in. Never translate.
